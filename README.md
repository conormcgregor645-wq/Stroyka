# Метраж — строительные калькуляторы

Сайт: **https://metrazh.online/**

Статический сайт с десятью калькуляторами ремонта. Работает без сервера и сборщика: подходит для GitHub Pages, Netlify или любого хостинга.

| Страница | Что считает |
|---|---|
| `plitka.html` | плитка для пола и стен, упаковки, клей, затирка, крестики |
| `oboi.html` | рулоны с учётом раппорта и подгонки, клей, обрезки |
| `kraska.html` | литры и банки краски, грунтовка, малярный скотч |
| `laminat.html` | упаковки ламината, подложка, плинтус, порожки |
| `shtukaturka.html` | мешки гипсовой или цементной штукатурки, маяки, грунтовка |
| `shpaklevka.html` | стартовая и финишная шпаклёвка, грунтовка, абразив |
| `gipsokarton.html` | листы ГКЛ, профиль, подвесы, саморезы, дюбели, серпянка |
| `uteplitel.html` | плиты и упаковки утеплителя, объём, пароизоляция, дюбели |
| `styazhka.html` | сухая смесь или цемент с песком, фибра, демпферная лента |
| `kirpich.html` | кирпич, раствор, цемент и песок для кладки |

Оформление: фон-миллиметровка, шрифты Manrope и JetBrains Mono (Google Fonts), тёмная карточка результата, схема комнаты в масштабе (SVG, для плитки и ламината — с раскладкой), на телефоне — прилипающая полоса с итогом внизу экрана. Цвета задаются переменными в начале `assets/style.css`.

На каждой странице калькулятора: хлебные крошки, блок «Как считается», таблица норм расхода, частые вопросы, разметка Schema.org (BreadcrumbList, FAQPage, WebApplication). Размеры комнаты запоминаются и подставляются в другие калькуляторы. Расчётом можно поделиться ссылкой или распечатать его.

## Структура

```
index.html, *.html     страницы (собраны скриптом tools/build.py)
404.html               страница «не найдено» для GitHub Pages
assets/style.css       общие стили; цвета — CSS-переменные в :root
assets/calc.js         формулы и логика всех калькуляторов
assets/partners.js     партнёрские ссылки на материалы и магазины
assets/site.js         Яндекс Метрика и реклама РСЯ
tools/build.py         генератор страниц, sitemap.xml, robots.txt и CNAME
sitemap.xml, robots.txt
CNAME                  домен для GitHub Pages (metrazh.online)
```

Шапка, меню, подвал, тексты и SEO-разметка всех страниц описаны в `tools/build.py`. После правок в нём пересоберите сайт:

```bash
python3 tools/build.py
```

Нужен только Python 3. Правки, внесённые вручную прямо в HTML, при пересборке затираются, поэтому меняйте тексты в `tools/build.py`.

## Заглушки, которые нужно заменить

| Заглушка | Где заменить | На что |
|---|---|---|
| `METRIKA_ID` | ✅ заменён на `113822395` в `assets/site.js` (`metrikaId`), `tools/build.py` (`metrika_counter`, для `<noscript>`) и на всех страницах | номер счётчика Яндекс Метрики |
| `RSY_BLOCK_ID` | `assets/site.js` (переменная `rsyBlockId`) | ID блока РСЯ, например `R-A-1234567-1` |
| `AFFILIATE_URL_*` | ✅ заменены на партнёрские ссылки Максидома в `assets/partners.js` (объект `SHOP`) | — |
| `YANDEX_VERIFICATION_CODE` | `tools/build.py`, шаблон `<head>`: раскомментировать строку, затем пересборка | код из Яндекс Вебмастера |
| `GOOGLE_VERIFICATION_CODE` | там же | код из Google Search Console |

Проще всего заменить заглушку поиском и заменой по всему проекту. Например, для Метрики:

```bash
grep -rl METRIKA_ID --exclude=README.md . | xargs sed -i 's/METRIKA_ID/98765432/g'
```

### Яндекс Метрика

Счётчик **113822395** подключается из `assets/site.js` на всех страницах. Чтобы сменить его, поменяйте номер в `assets/site.js` и `tools/build.py` и пересоберите страницы.

Сайт отправляет две цели (`reachGoal`). Создайте их в Метрике: «Цели → Добавить цель → JavaScript-событие».

| Идентификатор цели | Когда срабатывает | Параметры |
|---|---|---|
| `calc_done` | первый расчёт после ввода данных пользователем (один раз за визит) | `calc` — калькулятор |
| `affiliate_click` | клик по кнопке «Купить в Максидоме» или маленькой кнопке под ней | `calc` — калькулятор, `item` — ключ ссылки (например `PLITKA`, `ZATIRKA`), `shop` — `maxidom` |

### Партнёрские ссылки

Под каждым калькулятором стоит блок «Купить …» с кнопкой **«Купить в Максидоме»**. Все ссылки — партнёрские, через `https://uuwgc.com/`, ни одна не ведёт напрямую на maxidom.ru. Они открываются в новой вкладке, помечены `rel="sponsored nofollow"`, а клик отправляет в Метрику цель `affiliate_click`.

Ссылки и состав кнопок задаются в `assets/partners.js`, объект `SHOP`:

| Калькулятор | Кнопка «Купить в Максидоме» | Маленькие кнопки |
|---|---|---|
| Плитка | плитка | «Клей для плитки», «Затирка» |
| Обои | обои | — |
| Краска | краски для стен и потолков | «Грунтовка» |
| Ламинат | ламинат | — |
| Гипсокартон | гипсокартон | — |
| Штукатурка, шпаклёвка, утеплитель, стяжка, кирпич | строительные материалы | «Остальное» |

Под каждым блоком выводится маркировка: «Реклама. ООО МАКСИДОМ, ИНН 7804064663, erid: …». erid берётся автоматически из параметра `erid` ссылок, показанных в блоке. При смене ссылки или рекламодателя поменяйте `links`, `advertiser` и `inn` в `SHOP`.

### Реклама РСЯ

Место под блок находится между калькулятором и текстом статьи (`<div class="ad-slot" data-rsy>`). На телефоне оно идёт после результата и не перекрывает его. Пока `RSY_BLOCK_ID` не задан, блок скрыт и места не занимает. После замены `assets/site.js` сам подгружает `context.js` Яндекса и выводит блок.

## Домен и название сайта

Сайт работает на домене **metrazh.online**. Адрес и название заданы в начале `tools/build.py`:

```python
SITE_URL = "https://metrazh.online/"   # базовый адрес со слешем на конце
SITE_NAME = "Метраж"                   # шапка, подвал, og:site_name, страница 404
```

После изменения запустите `python3 tools/build.py`. Обновятся `canonical`, `og:url`, разметка Schema.org, `sitemap.xml`, `robots.txt` и файл `CNAME`. Для адреса на `*.github.io` файл `CNAME` удаляется.

### Подключение metrazh.online к GitHub Pages

1. В DNS у регистратора домена создайте записи для `metrazh.online`:

   | Тип | Имя | Значение |
   |---|---|---|
   | A | `@` | `185.199.108.153` |
   | A | `@` | `185.199.109.153` |
   | A | `@` | `185.199.110.153` |
   | A | `@` | `185.199.111.153` |
   | CNAME | `www` | `conormcgregor645-wq.github.io` |

   Для IPv6 можно добавить AAAA-записи `2606:50c0:8000::153`, `2606:50c0:8001::153`, `2606:50c0:8002::153`, `2606:50c0:8003::153`.
2. В репозитории: Settings → Pages → Custom domain. Там должно стоять `metrazh.online` (GitHub подхватывает его из файла `CNAME`). Нажмите Save.
3. Когда GitHub проверит DNS (от нескольких минут до суток), включите **Enforce HTTPS**.

Репозиторий называется `Stroyka`. Когда домен подключён, GitHub сам перенаправляет адрес `conormcgregor645-wq.github.io/Stroyka/` на https://metrazh.online/.

Старый адрес `conormcgregor645-wq.github.io/ai/` после переименования репозитория не работает: GitHub Pages не перенаправляет его ни на новое имя, ни на домен. Если эта ссылка где-то опубликована, замените её на https://metrazh.online/.

## Публикация на GitHub Pages

Settings → Pages → Deploy from a branch → `main`, папка `/ (root)`. Затем добавьте https://metrazh.online/ в Яндекс Вебмастер и Google Search Console и отправьте `https://metrazh.online/sitemap.xml`.

## Проверка формул

Все результаты округляются вверх: штуки, рулоны, мешки и упаковки — до целых, литры и килограммы — до десятых. Округление учитывает погрешность дробных чисел, поэтому 14,000000000000002 плитки считается как 14, а не 15. Контрольные примеры, посчитанные вручную и сверенные с калькуляторами:

| Калькулятор | Пример | Результат |
|---|---|---|
| Плитка | пол 3×2 м, плитка 30×30, запас 10%: 6 / 0,09 × 1,1 = 73,3 | 74 плитки |
| Плитка | стены 2×1,5×2,5 м − дверь 0,7×2, плитка 20×30, 10%: 16,1 / 0,06 × 1,1 = 295,2 | 296 плиток |
| Плитка | пол 1,2×1 м, 30×30, 5%: 1,2 / 0,09 × 1,05 = 14 ровно | 14 плиток |
| Обои | 4×3×2,7 м, дверь и окно, рулон 1,06×10,05: 12 полос по 2,8 м, 3 полосы из рулона | 4 рулона |
| Обои | то же, рулон 0,53, раппорт 64 см: 24 полосы по 3,2 м, 3 из рулона | 8 рулонов |
| Краска | стены 34,1 м², 2 слоя, 9 м²/л, 10%: 34,1 × 2 / 9 × 1,1 = 8,34 | 8,4 л |
| Ламинат | 5×4 м, упаковка 2,131 м², 7%: 21,4 / 2,131 = 10,04 | 11 упаковок |
| Штукатурка | стены 34,1 м², гипс 0,9 кг/м²·мм, слой 15 мм, 10%: 506,4 кг / 30 | 17 мешков |
| Шпаклёвка | 34,1 м²: старт 2 мм × 1,0 + финиш 1 мм × 1,2, 10% | 75,1 + 45,1 = 120,2 кг |
| Гипсокартон | обшивка 34,1 м², лист 3 м², 10%: 37,5 / 3 = 12,5 | 13 листов |
| Утеплитель | стены 34,1 м², 100 мм плитами 50 мм, 5%: 2 слоя, 100 плит / 8 | 13 упаковок |
| Стяжка | 5×4 м, 50 мм, ЦПС 2 кг/м²·мм, 5%: 2100 кг / 40 | 53 мешка |
| Кирпич | стена 6×3 м в кирпич, одинарный, шов 10 мм, 5%: 18 × 102,56 × 1,05 = 1938,5 | 1939 кирпичей |
