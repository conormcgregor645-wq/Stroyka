# РемонтКалк — калькулятор ремонта

Статический сайт с калькуляторами: сколько нужно **плитки**, **обоев**, **краски** и **ламината** на комнату. Без сборки и зависимостей — можно сразу выложить на GitHub Pages, Netlify или любой хостинг.

| Страница | Что считает |
|---|---|
| `plitka.html` | плитка (пол / стены / оба), упаковки, клей, затирка, крестики |
| `oboi.html` | рулоны с учётом раппорта и типа подгонки, клей, обрезки |
| `kraska.html` | литры и банки краски для стен/потолка, грунтовка, скотч |
| `laminat.html` | упаковки ламината, подложка, плинтус, заглушки, порожки |

Возможности: вычет окон и дверей, запас на подрезку, необязательный подсчёт стоимости, размеры комнаты запоминаются между калькуляторами, расчётом можно поделиться ссылкой или распечатать. На каждой странице — SEO-текст, FAQ и разметка schema.org (FAQPage, WebApplication).

## Партнёрские ссылки

Все магазины настраиваются в одном файле — `assets/partners.js`. Под каждым результатом выводится блок «Где купить» со ссылками на поиск нужного товара (плитка нужного размера, клей, затирка и т.д.).

1. Зарегистрируйтесь в партнёрской сети (Admitad, Яндекс Дистрибуция и т.п.) и подключите офферы строительных магазинов.
2. В `partners.js` пропишите в поле `wrap` шаблон deeplink-ссылки, например `https://ad.admitad.com/g/ВАШ_КОД/?ulp={url}`.
3. Проверьте, что поисковые URL магазинов (`search`) актуальны, при необходимости добавьте или удалите магазины.

Ссылки помечены `rel="sponsored nofollow"`, под блоком есть уведомление о партнёрских ссылках.

## Публикация

GitHub Pages: Settings → Pages → Deploy from a branch → ветка и папка `/ (root)`.

Если сайт будет на своём домене, замените `https://conormcgregor645-wq.github.io/ai/` на свой адрес в `<link rel="canonical">` и `og:url` всех страниц, в `sitemap.xml` и `robots.txt`.
